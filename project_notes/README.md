# Project-Specific Notes

Store project-specific knowledge here, such as:

- `glossary.md`: Domain & project terminology
- `architecture.md`: System components & integrations
- `workflows.md`: Enterprise business flows
- `roles.md`: RBAC matrix & permissions
- `environments.md`: Test environments & URLs
- `integrations.md`: Third-party APIs & ERP integrations
- `test-data.md`: Master data & transaction test data specs
- `open-questions.md`: Questions for BA/Architect

Project notes receive higher retrieval priority when project-specific context is requested.
