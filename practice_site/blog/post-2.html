Handling Browser Console Error Listener Assertions

Published on August 8, 2026 by QA Practice Team

Console Error Assertion Demo: This page automatically fires a real console.error() when loaded in the browser. Use Playwright's page.on('console', msg => ...)` to catch it.

Playwright allows test suites to listen for browser console messages during test execution using the console event listener on the Page object. 

// Playwright Python Example: Catching console.error
errors = []
page.on("console", lambda msg: errors.append(msg.text) if msg.type == "error" else None)
page.goto(url)
assert "Simulated runtime error" in errors[0]
