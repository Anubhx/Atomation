# 🏃 Agile Ceremonies, Sprint Planning & QA Integration

## 🎯 Overview: The Embedded Quality Engineer

In Agile environments, QA is not an external audit group—QA is an active participant in every Sprint ceremony from Day 1 to Day 10.

---

## 📅 QA Role Across Sprint Ceremonies

| Ceremony | Timing | QA Responsibilities & Outputs |
| :--- | :--- | :--- |
| **Backlog Grooming / Refinement** | Mid-Sprint | • Review user stories; define Given-When-Then Acceptance Criteria.<br>• Flag missing edge cases and enforce Definition of Ready (DoR). |
| **Sprint Planning** | Day 1 | • Estimate QA effort (test design, API automation, DB queries).<br>• Ensure automation tasks are included in story points. |
| **Daily Standup** | Daily (15 mins) | • Report test execution progress, blocking environment issues, and defect status.<br>• Coordinate with developers on PR readiness. |
| **Sprint Demo / Review** | Last Day | • Demonstrate completed, fully-verified features to stakeholders.<br>• Confirm Definition of Done (DoD) criteria satisfied. |
| **Retrospective** | Last Day | • Analyze escaped bugs and testing bottlenecks.<br>• Propose continuous quality process improvements. |
