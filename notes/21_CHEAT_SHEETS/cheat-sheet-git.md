# 🐙 Git Command Quick Reference Cheat Sheet

```bash
git checkout -b feature/po-automation # Create & switch to new branch
git add .                              # Stage changes
git commit -m "feat(qa): add P2P POM"  # Commit staged changes
git pull --rebase origin main         # Rebase latest main changes
git push origin feature/po-automation  # Push branch to remote
git status                             # Check file status
```
