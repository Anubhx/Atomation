# ✍️ Bug Reporting Quick Reference Cheat Sheet

## 📋 Standard Bug Report Structure
```text
Title: [Component][Action] Brief summary of failure behavior
Environment: Staging v2.4.1 | Chrome 127 | macOS
Severity: High | Priority: High
Preconditions: Test data records required
Steps to Reproduce: 1, 2, 3...
Expected Result: Explicit expected UI/API/DB behavior
Actual Result: Exact failure observed + HTTP error code
Evidence Attached: Trace zip, Console log snippet, DB SQL result
```
